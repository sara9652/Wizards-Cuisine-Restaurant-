🍽️ Wizards Cuisine

A modern, responsive restaurant landing page built with **HTML5** and **CSS3**. Wizards Cuisine is designed to provide an elegant user experience with a stylish hero section, smooth scrolling navigation, food menu, and restaurant locations.

---
 🌟 Overview

Wizards Cuisine is a frontend project created to practice responsive web design using pure HTML and CSS. The website features a clean restaurant UI with attractive typography, gradient sections, and a mobile-friendly layout.
✨ Features

* Responsive landing page
* Modern restaurant UI
* Smooth scrolling navigation
* Hero section with call-to-action
* Food menu using CSS Grid
* Restaurant locations section
* Font Awesome icons
* CSS variables for theme colors
* Mobile-friendly design

## 🛠️ Built With

* HTML5
* CSS3
* Flexbox
* CSS Grid
* Font Awesome
